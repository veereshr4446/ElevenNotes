# ElevenNotes

**Your Student Life, Organized.**
Academics · Productivity · Growth

ElevenNotes is a free student toolkit in plain HTML, CSS and JavaScript. No backend, no login, no build step.

## What is inside
- **Dashboard**: your subjects, faculty, timetable, important dates and events
- **Academic tools**: SGPA calculator, attendance what-if calculator, exam countdown
- **Faculty**: directory with a private star-rating interface
- **Notes**: keep Google Drive links to your notes per subject
- **Planner**: tasks with subject, priority and date
- **Pomodoro focus timer** with session history and streak
- **Profile**: set your own name, USN, bio and avatar
- **Social hub**: study groups and a community link
- Dark and light theme, mobile friendly

## Privacy
- No account, no login, no server. Nothing you enter leaves your browser.
- Your name, USN, tasks, notes, ratings and settings are saved only in your browser's LocalStorage.
- ElevenNotes is **not connected to any college system or third-party portal**. It does not read, fetch or store attendance or marks.
- Subjects, faculty, timetable and dates shown are sample content for demonstration.

## Run locally
Open `index.html` in a browser. For auto-reload while editing, use the VS Code Live Server extension.

## Structure
```
index.html
css/style.css
js/app.js      behaviour: navigation, tools, planner, profile, timer, theme
js/data.js     sample subjects, faculty and exam dates
images/        logo, avatars, profile photo
audio/         focus music used in the About modal
```
